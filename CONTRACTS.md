# Module contracts — Sehat Saathi build

Coordination document for parallel implementation. **`lib/schema.ts` is already written and is the single source of truth for shared types — import from `@/lib/schema`, never redefine.** Import alias `@/*` → project root. Next.js 16 App Router, React 19, TypeScript strict, Tailwind v4 (CSS-first config: `@import "tailwindcss"` + `@theme inline` in `app/globals.css` — there is NO tailwind.config file). Deps available: `openai`, `pdfjs-dist`.

Design language (all UI): mobile-first, very large touch targets (min 64px), rounded-2xl cards, emerald/teal primary palette on warm white; dark text; Urdu rendered in `var(--font-urdu)` (Noto Nastaliq Urdu, loaded in layout), Latin in `var(--font-sans)` (Inter). Generous line-height for Nastaliq (leading-loose). App is Urdu-first: default lang "ur", `dir="rtl"` on `<html>` when ur.

## Track A — Server AI core (owns: `lib/qwen.ts`, `lib/prompts.ts`, `lib/vote.ts`, `app/api/chat/route.ts`, `app/api/extract/route.ts`, `app/api/safety/route.ts`, `app/api/verify/route.ts`)

`lib/qwen.ts` (server-only):
- `export const qwen: OpenAI` — `new OpenAI({ apiKey: process.env.DASHSCOPE_API_KEY, baseURL: process.env.DASHSCOPE_BASE_URL ?? "https://dashscope-intl.aliyuncs.com/compatible-mode/v1" })`
- `export const VISION_MODEL = process.env.QWEN_VISION_MODEL ?? "qwen3.7-plus"`
- `export const REASONING_MODEL = process.env.QWEN_REASONING_MODEL ?? "qwen3.7-max"`
- `export function parseJsonLoose(text: string): unknown` — strips ``` fences, finds first `{`..last `}`, JSON.parse; throws on failure.
- `export async function timed<T>(label: string, model: string, fn: () => Promise<T>, trace: PipelineStep[]): Promise<T>` — runs fn, pushes {model,label,ms}.

`lib/prompts.ts`: exported string constants / builder fns:
- `CHAT_SYSTEM(lang: Lang): string` — medical assistant for low-literacy Pakistani users. Reply in simple Urdu (5th-grade level, short sentences) when lang="ur", simple English when "en". Never diagnose, never prescribe, never guess doses. If the user describes red-flag symptoms (chest pain, difficulty breathing, heavy bleeding, unconsciousness, stroke signs), start reply with the literal token `[RED_FLAG]` then tell them to go to hospital / call Rescue 1122. Occasionally remind: this is not a doctor.
- `EXTRACTION_PROMPT: string` — the closed-vocabulary prescription extraction prompt. Must include: the Urdu enums (صبح دوپہر شام رات، کھانے سے پہلے/بعد، خالی پیٹ، ایک/آدھی/دو گولی، دن میں ایک/دو/تین بار، ہر ۸ گھنٹے), Latin abbreviations table (OD=once, BD=twice, TDS=thrice, QID=4x, HS=bedtime, SOS/PRN=as needed, 1-0-1 patterns, ½), Eastern Arabic numerals ۱۲۳۴۵۶۷۸۹۰, instruction to read drug names as Latin script, dual output (raw strings + normalized enums), times derivation (once→["21:00"] if HS else ["08:00"]; twice→["08:00","20:00"]; thrice→["08:00","14:00","20:00"]; 4x→["06:00","12:00","18:00","23:00"]), never guess unreadable fields (use "unknown"/null + list region in unreadable_regions + needs_user_confirmation=true), STRICT JSON only matching `ExtractionResult`, no prose.
- `SAFETY_PROMPT(medicines, lang): string` — for Max: given medicine list JSON, find duplicate active ingredients (e.g. paracetamol in Panadol + combination products), known dangerous interactions, implausible doses/frequencies for that drug. Output STRICT JSON matching `SafetyResult`. text_ur in simple Urdu.
- `GROUNDING_PROMPT(extraction): string` — for Max: given voted ExtractionResult, sanity-check each medicine's frequency/dose against typical dosing for that drug; return SafetyResult (implausible → per_medicine.plausible=false with notes).
- `VERIFY_PROMPT(medicines): string` — for Plus with box photo: identify the medicine in the photo, compare against the provided list, read expiry date if visible. STRICT JSON matching `VerifyResult`.

`lib/vote.ts`:
- `export function voteExtractions(runs: ExtractionResult[]): ExtractionResult` — group medicines across runs by normalized brand_name (lowercase, strip spaces/digits-suffix fuzz: startsWith or Levenshtein≤2). Per group: majority vote each enum field; times from voted frequency; strings: pick from the run agreeing with majority frequency (else first non-null). Disagreement on any of quantity/frequency/food → needs_user_confirmation=true and confidence.directions=min. Medicines appearing in <ceil(n/2) runs are dropped UNLESS n≤2 (keep all). overall_confidence = mean of per-medicine confidences × (agreement ratio).

API routes (all `export async function POST(req: Request)`, `export const runtime = "nodejs"`, `export const maxDuration = 120`): implement shapes from schema.ts exactly. `/api/chat`: strip `[RED_FLAG]` token from reply, set red_flag boolean. Images: content parts `{type:"image_url", image_url:{url:dataUrl}}` on last user message. `/api/extract`: N parallel Plus runs (Promise.allSettled, keep fulfilled; if 0 fulfilled → 502 with error json) → vote → Max grounding (try/catch, null on failure) → response. temperature 0.3 for extraction runs, 0.7 chat. Errors: return Response.json({error: string}, {status}) — user-facing messages must be bilingual-safe (client shows its own strings). Never log the API key. All routes wrap total work in trace steps.

## Track B — Client platform libs (owns: `lib/i18n.tsx`, `lib/translations.ts`, `lib/speech.ts`, `lib/alarms.ts`, `lib/idb.ts`, `lib/image.ts`)

`lib/translations.ts`: `export type TKey = ...` (string-literal union) and `export const translations: Record<TKey, { ur: string; en: string }>`. Keys needed by UI (superset ok): app_name, tagline, home_alarms, home_chat, home_hint, chat_placeholder, chat_send, chat_listening, chat_tap_mic, chat_attach, chat_thinking, action_read_rx, action_check_box, action_just_ask, alarms_title, alarms_empty, alarms_add, alarms_test, alarm_taken, alarm_snooze, alarm_ring_title, add_photo, medicine_name, times_label, duration_label, food_before, food_after, food_empty, food_milk, food_any, freq_once, freq_twice, freq_thrice, freq_four, freq_bedtime, freq_needed, morning, noon, evening, night, save, cancel, delete, confirm_schedule, confirm_yes, confirm_retake, disclaimer, red_flag_banner, call_1122, verify_match, verify_mismatch, verify_unsure, expired_warning, error_generic, error_offline, speak_screen, language_toggle, extract_review_title, extract_low_confidence, dev_panel_title, adherence_title.
`lib/i18n.tsx` (client): `LanguageProvider` (React context; persists to localStorage LS_LANG; default "ur"; sets `document.documentElement.lang/dir` in effect) and `useLang(): { lang: Lang; setLang(l: Lang): void; t(k: TKey): string; dir: "rtl" | "ltr" }`.

`lib/speech.ts` (client, no React): 
- `sttSupported(): boolean`; `listen(lang: Lang, onInterim?: (s: string) => void): Promise<string>` (SpeechRecognition, `ur` → lang "ur-PK", en → "en-US"; rejects on error/no-speech); `stopListening(): void`
- `initAudio(): void` — create+resume singleton AudioContext (call on first tap); `beepPattern(): void` — single tone via oscillator, repeats ~every 700ms and self-stops after ~4.5s (not a loop that runs the whole ring duration); `stopBeeps(): void`
- `speak(text: string, lang: Lang, fallbackText?: string): Promise<void>` — tries Google Cloud TTS first (POST `/api/tts`, response cached per (lang,text)); on failure falls back to browser speechSynthesis speaking `fallbackText ?? text` (pick voice whose lang startsWith "ur" for ur, else set utterance.lang="ur-PK" and try anyway; en → "en-"). `stopSpeaking(): void` cancels either engine.
- `app/api/tts/route.ts` — POST `{ text, lang }` → `audio/mpeg` bytes via Google Cloud TTS (`GOOGLE_TTS_API_KEY` env var; `ur` → voice `ur-IN`); 503 if the key isn't configured.

`lib/idb.ts` (client): minimal IndexedDB kv (db "sehat-saathi", store "kv"): `idbSet(key: string, value: string): Promise<void>`, `idbGet(key: string): Promise<string | null>`, `idbDel(key: string): Promise<void>`.

`lib/alarms.ts` (client): CRUD over localStorage LS_ALARMS (`loadAlarms(): Alarm[]`, `saveAlarm(a: Alarm)`, `deleteAlarm(id)`, `logDose(id, date, time, status)` appends to taken_log). Scheduling helpers: `isActiveOn(a: Alarm, date: Date): boolean` (start_date ≤ date < start+duration; null duration = forever); `findDueAlarm(now: Date): { alarm: Alarm; time: string } | null` — scans alarms, active date, |now − slot| ≤ 60s, not in LS_FIRED registry; `markFired(alarmId, date, time)`; `clearOldFired()` (drop entries not from today). `buildAlarmsFromExtraction(result: ExtractionResult, photoDataUrl: string | null): Promise<Alarm[]>` — creates Alarm objects (stores photo in idb under key `photo_${alarmId}`, urdu_announcement composed from name + quantity + food in Urdu words).

`lib/image.ts` (client): `fileToDataUrl(f: File): Promise<string>`; `preprocess(dataUrl: string, opts?: { maxDim?: number; grayscale?: boolean }): Promise<string>` — canvas: downscale to maxDim (default 1600), optional grayscale + contrast stretch, JPEG 0.85; `thumbnail(dataUrl: string, dim?: number): Promise<string>` (default 300, JPEG 0.7); `pdfFirstPageToDataUrl(f: File): Promise<string>` — dynamic `import("pdfjs-dist")`, set `GlobalWorkerOptions.workerSrc = new URL("pdfjs-dist/build/pdf.worker.min.mjs", import.meta.url).toString()`, render page 1 at scale≈2 to canvas → JPEG.

## Track E — Eval harness + docs (owns: `eval/run.mjs`, `eval/labels.example.json`, `eval/README.md`, root `README.md`, `.env.example`)

- `eval/run.mjs`: Node script (no deps): reads `eval/images/*.{jpg,jpeg,png}` + `eval/labels.json`, POSTs each image (base64 data URL) to `http://localhost:3000/api/extract` (env EVAL_URL override), compares per-field (brand_name: case-insensitive substring match either direction; frequency/food/quantity: exact; duration_days: exact; times: set equality) against label, prints per-image and aggregate per-field accuracy table + overall. Handles multi-medicine labels (match by brand substring). Exit non-zero if any request fails.
- `eval/labels.example.json`: 2 example entries documenting the shape `{ "image": "rx1.jpg", "medicines": [{ brand_name, quantity, frequency, food, duration_days, times }] }`.
- `eval/README.md`: how to collect 20 photos, label, run (`npm run dev` then `node eval/run.mjs`), iterate on prompt.
- Root `README.md` (overwrite CNA boilerplate): project description (from PROJECT-PLAN.md §1–3), feature list, architecture diagram (ascii), both-models usage explanation (judging), setup (env vars table, npm install/dev/build), eval instructions, deploy to Vercel note, team members section (placeholder list), demo link placeholder, safety disclaimer.
- `.env.example`: DASHSCOPE_API_KEY=sk-..., DASHSCOPE_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1, QWEN_VISION_MODEL=qwen3.7-plus, QWEN_REASONING_MODEL=qwen3.7-max, EVAL_URL (optional).
